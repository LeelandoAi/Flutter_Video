## ADDED Requirements

### Requirement: 统一播放控制器 API
播放器库 SHALL（必须）暴露公开控制器 API，用于打开媒体、播放、暂停、跳转、停止、释放、设置倍速、设置缩放模式、进入全屏、退出全屏，并报告当前播放状态；业务方不需要接触具体后端控制器类型。

#### Scenario: 应用通过统一控制器操作播放
- **WHEN** 应用通过统一控制器打开视频源，并调用播放、暂停、跳转和释放
- **THEN** 当前激活内核必须收到等价操作，应用也必须能通过共享状态 API 观察到标准化状态变化

#### Scenario: 后端实现对业务方隐藏
- **WHEN** 当前激活内核是 Media Kit、FVP、官方 Video Player 或其他已注册适配器
- **THEN** 使用控制器的应用代码不得为了执行基础播放操作而导入后端专属控制器类

### Requirement: 可插拔内核注册表
播放器库 SHALL（必须）提供内核注册表，允许播放适配器注册、通过稳定内核 id 标识、查询能力、显式选择和自动选择。

#### Scenario: 偏好内核兼容
- **WHEN** 调用方请求一个已注册且支持当前平台和媒体源的内核
- **THEN** 控制器必须使用该内核，并在播放器状态中暴露该内核 id

#### Scenario: 偏好内核不兼容
- **WHEN** 调用方请求的内核未注册，或不支持当前平台/媒体源
- **THEN** 控制器必须从调用方偏好列表中选择下一个兼容降级内核，或者返回确定性的“不支持内核”错误

### Requirement: 跨平台目标支持
播放器库 SHALL（必须）支持 Android、iOS、Windows、macOS，并且只选择内核描述中声明兼容当前平台的内核。

#### Scenario: 存在平台兼容内核
- **WHEN** 应用运行在 Android、iOS、Windows 或 macOS，且至少一个已注册内核支持当前平台上的请求播放源
- **THEN** 控制器必须使用兼容内核初始化播放

#### Scenario: 不存在兼容内核
- **WHEN** 应用运行在目标平台，但没有任何已注册内核支持请求播放源
- **THEN** 控制器必须在播放开始前失败，并在错误中包含平台、播放源类型和候选内核诊断信息

### Requirement: 能力报告
播放器库 SHALL（必须）为每个已注册内核暴露标准化能力信息，包括支持平台、播放源类型、渲染能力、字幕能力、音轨能力、倍速能力、缩放能力和已知限制。

#### Scenario: 应用在播放前检查能力
- **WHEN** 应用从注册表查询可用内核
- **THEN** 注册表必须返回能力描述，让应用可以判断每个内核是否满足当前播放需求

### Requirement: 标准化播放器状态
控制器 SHALL（必须）发布标准化不可变状态，包含生命周期、当前位置、总时长、已缓冲区间、当前播放源、当前内核 id、缩放模式、播放倍速、全屏状态、可用时的已选轨道和错误诊断。

#### Scenario: 内核报告缓冲
- **WHEN** 当前后端报告缓冲中
- **THEN** 控制器状态必须进入缓冲状态，并保留当前位置、总时长、播放源和当前内核 id

#### Scenario: 播放失败
- **WHEN** 当前后端打开播放源失败或播放过程中失败
- **THEN** 控制器状态必须进入失败状态，并包含标准化错误码以及可用时的后端诊断信息

### Requirement: 默认影视播放器控件
播放器库 SHALL（必须）提供可复用 Flutter 影视播放器组件，包含进度、当前时间、总时长、上一集、下一集、播放、暂停、全屏、切换内容或内核入口、缩放模式选择和倍速选择。

#### Scenario: 已加载视频时显示默认控件
- **WHEN** 视频源已就绪
- **THEN** 默认组件必须展示进度、上一集、下一集、播放或暂停、全屏、缩放模式和播放倍速控件

#### Scenario: 未提供选集回调
- **WHEN** 应用未提供上一集或下一集回调
- **THEN** 默认组件必须禁用或隐藏上一集/下一集按钮，且不得影响其他播放控件

### Requirement: 缩放模式预设
播放器库 SHALL（必须）通过公开控制器和默认 UI 支持 `original`、`ratio16x9`、`ratio4x3`、`contain`、`fill`、`cover` 缩放模式。

#### Scenario: 用户选择受支持缩放模式
- **WHEN** 用户从默认 UI 选择一个必需缩放模式
- **THEN** 控制器必须应用该缩放模式，并在标准化状态中发布所选值

#### Scenario: 内核无法应用请求的缩放模式
- **WHEN** 当前内核无法支持所选缩放模式
- **THEN** 控制器必须报告“不支持能力”错误，而不是静默应用其他缩放模式

### Requirement: 播放倍速预设
播放器库 SHALL（必须）通过公开控制器和默认 UI 支持 `0.5`、`0.75`、`1.0`、`1.25`、`1.5`、`1.75`、`2.0`、`3.0` 播放倍速。

#### Scenario: 用户选择受支持倍速
- **WHEN** 用户选择一个必需倍速档位
- **THEN** 控制器必须请求当前内核应用该倍速，并在标准化状态中发布所选倍速

#### Scenario: 内核无法应用请求的倍速
- **WHEN** 当前内核无法支持所选倍速
- **THEN** 控制器必须报告“不支持能力”错误，而不是静默裁剪到其他倍速

### Requirement: 全屏行为
播放器库 SHALL（必须）提供标准化全屏 API，并支持从默认 UI 或直接控制器调用在 Android、iOS、Windows、macOS 上进入和退出全屏。

#### Scenario: 应用进入全屏
- **WHEN** 用户点击全屏控件，或应用调用全屏 API
- **THEN** 播放器必须以当前平台的方式进入全屏呈现，并在标准化状态中发布全屏状态

#### Scenario: 应用退出全屏
- **WHEN** 用户退出全屏，或应用调用退出全屏 API
- **THEN** 播放器必须回到内嵌呈现，并在标准化状态中发布非全屏状态

### Requirement: 播放源和内核切换
播放器库 SHALL（必须）允许应用通过公开 API 切换当前媒体源，并在兼容时切换当前播放内核；应用代码不需要重新创建后端专属控制器对象。

#### Scenario: 应用切换到下一集
- **WHEN** 应用使用新播放源触发下一集动作
- **THEN** 控制器必须关闭旧播放源、打开新播放源，并保留适用的播放器选项，例如缩放模式和倍速

#### Scenario: 应用为当前播放源切换内核
- **WHEN** 应用为当前播放源请求切换到另一个兼容内核
- **THEN** 控制器必须释放旧内核、初始化新内核，并尝试恢复播放源、播放位置、缩放模式和倍速

### Requirement: 适配器生命周期安全
播放器库 SHALL（必须）为初始化、打开播放源、播放命令、状态订阅、错误上报和释放定义统一适配器生命周期。

#### Scenario: 控制器被释放
- **WHEN** 应用释放统一控制器
- **THEN** 当前适配器必须释放原生资源，后续播放命令必须以“控制器已释放”错误失败

#### Scenario: 切换内核时释放资源
- **WHEN** 控制器从一个内核切换到另一个内核
- **THEN** 旧适配器必须在新适配器开始播放前被释放

### Requirement: 文档和示例
播放器库 SHALL（必须）包含文档和示例应用，演示统一 API 用法、适配器注册、内核偏好选择、默认控件、缩放模式、倍速档位、全屏和平台支持限制。

#### Scenario: 开发者运行示例
- **WHEN** 开发者打开示例应用
- **THEN** 示例应用必须演示通过统一控制器播放视频，并展示如何选择或偏好某个播放内核
