## 2. 核心 API 和状态模型

- [x] 2.1 定义播放源、播放源类型、媒体元数据、缓冲区间、音轨、字幕和标准化错误模型。
- [x] 2.2 定义 `UnifiedVideoState`，包含生命周期、时间线、播放源、当前内核 id、缩放模式、倍速、全屏、轨道、诊断信息和降级历史。
- [x] 2.3 定义公开控制器 API，覆盖打开、播放、暂停、跳转、停止、释放、全屏、缩放模式、倍速、切换播放源和切换内核。
- [x] 2.4 定义缩放模式枚举值：原始、16:9、4:3、contain、fill、cover。
- [x] 2.5 定义播放倍速档位：0.5、0.75、1.0、1.25、1.5、1.75、2.0、3.0。

## 3. 播放器内核抽象

- [x] 3.1 定义播放适配器接口，覆盖初始化、打开播放源、处理播放命令、转发状态/事件、创建播放画面和释放资源。
- [x] 3.2 定义 `VideoKernelDescriptor`，包含平台支持、播放源支持、渲染支持、字幕支持、音轨支持、倍速支持、缩放支持和已知限制。
- [x] 3.3 实现内核注册表，支持注册、查找、能力查询、精确选择、有序偏好选择、自动选择和“不支持内核”诊断。
- [x] 3.4 实现降级行为，记录被跳过的内核，并在控制器状态中暴露降级历史。
- [x] 3.5 增加假内存适配器，用于控制器、注册表、生命周期和 UI 测试。
