# Leelando Video 跨端播放器 View 设计规格

日期：2026-08-27  
状态：设计已确认，暂不实施 Flutter 代码  
视觉稿：[Liquid Glass Player UI](../../design/player-view/liquid-glass-player-ui.html)

## 1. 设计结论

播放器采用“画面优先、主控贴边、浮层才用玻璃”的方案。

- 主控制层全部无可见背景：上一集、播放／暂停、下一集、选集、弹幕、倍速、更多和全屏直接叠在视频画面上。
- 进度条独立显示在主控制行上方，不放入卡片、胶囊或玻璃面板。
- 主控制行尽可能贴近底部：手机竖屏嵌入为 `1 pt`，桌面嵌入为 `2 dp`，手机横屏／全屏为 `safe-area inset + 0`。
- `44 × 44` 的触控热区只向上和左右扩展，不通过增加底部留白来满足触控尺寸。
- Liquid Glass 只用于用户主动打开的选集、倍速和设置浮层。
- 选集只在横屏、全屏或桌面宽布局出现；手机竖屏嵌入不显示选集。

## 2. 设计范围

本规格覆盖 `UnifiedVideoPlayer` 的像素层，不改变控制器、内核或播放协议：

- 手机竖屏业务页嵌入播放器。
- 手机横屏与全屏播放器。
- Windows / macOS 业务页嵌入播放器。
- 选集、倍速、更多设置浮层。
- 打开、缓冲、暂停、失败、结束状态。
- 不同尺寸下的显隐、触控和安全区规则。

本轮不包含：Flutter Widget 重构、依赖变更、动画实现、测试修改或示例应用改造。

## 3. 信息架构

### 3.1 一级常驻控制

从左到右固定为：

1. 上一集。
2. 播放／暂停。
3. 下一集。
4. 选集，仅符合显隐条件时出现。
5. 弹幕。
6. 倍速。
7. 更多，仅非紧凑模式出现。
8. 全屏／退出全屏。

进度条和时间位于这行上方：左侧当前时间，右侧总时长，数字使用等宽数字特性。

当上一集或下一集回调不存在时，保留按钮槽位并使用 `34%` 白色不透明度禁用，避免播放按钮横向跳动。无障碍语义应同时报告“不可用”。

### 3.2 二级设置

以下能力不出现在一级主控行：

- 镜像。
- 左转／右转。
- 画面比例与缩放模式。
- 夜间模式。
- 播放内核切换。
- 内核诊断与降级历史。

它们进入“更多”浮层，并按一个连续面板加发丝分隔线组织，不使用 Chip 网格。

## 4. 三种响应模式

| 模式 | 判定建议 | 显示 | 隐藏 |
|---|---|---|---|
| Compact | 手机竖屏、非全屏；或播放器宽度小于 `480` | 上一集、播放暂停、下一集、弹幕、倍速、全屏 | 选集、更多、播放器标题栏 |
| Expanded | 手机横屏或全屏 | 全部一级控制、标题、副标题 | 无 |
| Wide | Windows / macOS 且播放器宽度不小于 `640` | 全部一级控制、标题、副标题 | 无 |

选集的明确判定为：

```text
showEpisodePicker = fullscreen || mobileLandscape || desktopWide
```

组件应优先使用平台、方向和全屏状态判定模式；`LayoutBuilder.maxWidth` 仅作为嵌入组件的二级保护条件，避免宿主页面侧栏把播放器压得过窄。

## 5. 基准画布与尺寸

### 5.1 手机竖屏嵌入

- 设计画布：`393 × 852 pt`。
- 播放器：`393 × 221 pt`，比例 `16:9`。
- 左右主控内边距：`7 pt`。
- 视觉底距：`1 pt`。
- 进度轨高度：`2 pt`。
- 普通运输图标：`17 pt`。
- 播放／暂停图标：`23 pt`。
- 文字操作：`9 pt / 650`。
- 点击区：至少 `44 × 44 pt`，向上扩展。
- 选集与更多隐藏。

### 5.2 手机横屏／全屏

- 设计画布：`852 × 393 pt`。
- 主控左边界：左侧系统安全区之后 `0–8 pt`。
- 主控右边界：`24 pt`。
- 视觉底距：系统底部安全区之后 `0 pt`。
- 进度轨高度：`3 pt`。
- 普通图标：`21 pt`。
- 播放／暂停图标：`29 pt`。
- 文字操作：`13 pt / 650`。
- 标题：`18 pt / 650 / -0.02em`。
- 副标题：`11 pt / 500`，白色 `66%`。
- 点击区：至少 `44 × 44 pt`。

视觉稿以 Dynamic Island 一代 iPhone 的横屏安全区为示意。实际实现必须读取 `MediaQuery.viewPadding`，不得把 `59 / 21` 等示意值写死。

### 5.3 桌面业务页嵌入

- 播放器设计基准：`1280 × 720 dp`。
- 推荐业务页最大播放器宽度：`1280 dp`。
- 完整 Wide 模式最小宽度：`640 dp`。
- 播放器圆角：`18 dp`；进入全屏后为 `0`。
- 左右主控内边距：`14 dp`。
- 视觉底距：`2 dp`。
- 进度轨高度：`3 dp`。
- 普通图标：`21 dp`。
- 播放／暂停图标：`29 dp`。
- 点击区：至少 `44 × 44 dp`。

## 6. 色彩与材质

### 6.1 页面与文本

- 页面底色：`#F5F5F7`。
- 页面表面：`#FFFFFF`。
- 主文本：`#1D1D1F`。
- 次文本：`#6E6E73`。
- 发丝线：`rgba(0,0,0,0.07)`。
- 唯一操作强调色：`#0071E3`；视频深色背景上的激活态可使用 `#7EC3FF` 提升对比。

### 6.2 视频上的主控

- 图标与文字：白色 `94–100%`。
- 禁用控件：白色 `34%`。
- 次级说明：白色 `62–66%`。
- 主控容器背景：无。
- 图标投影：`0 2px 6px rgba(0,0,0,0.8)`，只用于保证复杂画面上的可读性。
- 视频底部允许有高度不超过 `96 pt` 的不可感知黑色渐隐区；不得呈现为可识别工具栏。

### 6.3 Liquid Glass 浮层

- 深色玻璃：`rgba(30,30,34,0.70)`。
- 模糊：`20`。
- 饱和度：`180%`。
- 边框：`1px rgba(255,255,255,0.14)`。
- 圆角：Popover `18`，Sheet 顶部 `22`。
- 阴影：`0 2px 8px rgba(0,0,0,0.10), 0 30px 80px rgba(0,0,0,0.24)`。
- `prefers-reduced-transparency` 或平台降低透明度时，替换为不透明 `#1E1E22`。

主控行严禁使用玻璃、卡片或胶囊背景。玻璃只属于浮层。

## 7. 浮层规格

### 7.1 选集

- 入口只在 Expanded / Wide 模式显示。
- 手机横屏使用右侧边缘面板，宽度为可用宽度的 `42–58%`，最大 `360 pt`。
- 桌面使用锚定在“选集”入口上方的 Popover，建议宽 `320 dp`、最大高 `420 dp`。
- 集数使用一个连续面板与发丝分隔线，不为每集创建独立卡片。
- 当前集使用单一蓝色文字和勾选，不添加彩色背景条。
- 选择新集后浮层沿原路径退出，并显示打开／缓冲状态。

### 7.2 倍速

- Popover 锚定倍速文字。
- 宽度 `154–180`。
- 每行高度至少 `44`。
- 使用完整预设：`0.5`、`0.75`、`1.0`、`1.25`、`1.5`、`1.75`、`2.0`、`3.0`。
- 当前倍速以蓝色文字与勾选标识，不使用黄色。

### 7.3 更多设置

- 手机使用底部 Sheet；桌面使用右下锚定 Popover。
- Sheet 顶部圆角 `22`，底部贴边，保留系统安全区。
- 手机 Sheet 有 `38 × 5` 的拖拽把手。
- 分组顺序：画面、播放、播放器内核、诊断。
- 设置行高度至少 `46`，同组使用发丝分隔线。

## 8. 状态反馈

| 状态 | 视觉 | 交互 |
|---|---|---|
| opening | 白色细线 Spinner + “正在加载视频” | 主控隐藏 |
| buffering | Spinner + “正在缓冲”，保留当前位置 | 主控可通过点击重新显示 |
| paused | 中心播放图标 + “已暂停” | 点击画面或播放按钮继续 |
| switchingKernel | “正在切换到 {内核名}” | 禁止重复切换，不锁死其他退出操作 |
| failed | 单色错误图标、具体错误文案、蓝色“重试” | 可重试；更多中可切换内核 |
| ended | 重播图标 + “重播 / 下一集” | 上一集和下一集保持可用 |

内核切换失败但当前内核仍可播放时，使用顶部短暂消息，不用全屏错误层。

## 9. 显隐与交互

- 播放中：用户最后一次有效交互后 `3 秒`隐藏控制层。
- 暂停、失败、结束：控制层保持显示。
- 拖动进度条：禁止自动隐藏；结束拖动后重新计时。
- 手机：点击画面切换控制层显隐。
- 桌面：鼠标移入、移动、按下、滚轮、键盘操作立即显示。
- 控件按下立即反馈，建议缩放到 `0.96–0.97`，不等待抬起。
- 浮层进入约 `400 ms`，退出约 `260 ms`，使用同一路径并允许中途反向。
- 降低动态效果时，浮层改为 `200 ms` 淡入淡出，不做位移。

## 10. 图标与文字

- 图标统一使用 `24 × 24` 网格和 `1.75` 线宽；播放、暂停、上一集、下一集允许实心媒体符号。
- 普通操作图标使用白色；只有激活弹幕等单一状态使用蓝色。
- 不使用 Emoji、彩色图标或灰色方块占位。
- 字体使用系统 SF / PingFang 字体栈。
- 标题采用负字距；时间与倍速使用 tabular figures。

## 11. `flutter_autosize_screen` 映射

目标库的发布文档要求在入口设置标准尺寸、使用 `runAutoApp`，并通过 `AutoSizeUtil.appBuilder` 替换根 `MaterialApp` 的 `MediaQuery`。它在横向宽度大于高度时以高度作为缩放基准。因此设计稿使用“短边基准”交接：

- 手机标准短边：`393`。
- 桌面标准短边：`720`。
- 手机竖屏按 `393 × 852` 写设计值。
- 手机横屏按 `852 × 393` 写设计值。
- 桌面按 `1280 × 720` 写设计值。

宿主应用需要按目标平台在启动时选择标准短边；播放器组件本身不应在内部再次初始化全局绑定。

实现时需要注意：

1. 安全区必须来自 `MediaQuery.viewPadding`，不能按缩放后的固定数字模拟。
2. 组件布局判定优先使用 `Orientation`、全屏状态和桌面平台；不要只依赖缩放后的全局屏幕宽度。
3. 嵌入宽度必须来自局部 `LayoutBuilder`，不能用全局 `MediaQuery.size.width` 代替。
4. 触控热区的最小 `44` 需要在缩放后仍可用；必要时对热区做下限约束。
5. 在正式实施前，应先验证 `flutter_autosize_screen 1.0.1` 与本仓库 Flutter / Dart 版本的依赖解析和自定义 Binding 行为。该包当前公开版本较旧，但本设计阶段不更换依赖。

参考：[flutter_autosize_screen package](https://pub.dev/packages/flutter_autosize_screen)、[API documentation](https://pub.dev/documentation/flutter_autosize_screen/latest/)。

## 12. 无障碍

- 所有按钮暴露明确语义：上一集、暂停、下一集、打开选集、关闭弹幕、播放速度 1.0 倍、更多设置、进入全屏。
- 图标可见尺寸不等于点击尺寸；所有交互目标至少 `44 × 44`。
- 控制层不能只依赖 Hover。
- 文本缩放后若紧凑模式溢出，按优先级隐藏更多、倍速文字标签和弹幕文字，但保留语义化图标与播放控制。
- 颜色不是唯一状态信号；激活态同时使用勾选或实心图标。

## 13. 验收清单

- [ ] 手机竖屏不显示选集和更多。
- [ ] 手机横屏、全屏和桌面宽布局显示选集。
- [ ] 主控行没有任何可见背景、胶囊、卡片或玻璃。
- [ ] 手机竖屏底距 `1 pt`，桌面底距 `2 dp`，全屏额外底距 `0`。
- [ ] 系统安全区没有被固定数字替代。
- [ ] 所有控件热区至少 `44 × 44`，且不会把视觉底距撑大。
- [ ] 上一集、播放暂停、下一集顺序固定，禁用时布局不位移。
- [ ] 选集、倍速、设置浮层使用 Liquid Glass；普通内容不用玻璃。
- [ ] 选集和设置项使用连续面板加发丝分隔线。
- [ ] 只有一个蓝色强调色，没有当前实现中的黄色选中态。
- [ ] 时间与倍速使用等宽数字。
- [ ] 控制层自动隐藏、进度拖动、失败、结束和内核切换状态均有定义。
- [ ] 降低动态效果、降低透明度和高对比度模式有降级方案。

## 14. 设计自检

- Surface：业务页面使用 `#F5F5F7` 与白色连续面板，播放器本体以视频画面为表面。
- Glass：只用于选集、倍速和设置浮层。
- Type：系统字体、标题负字距、时间等宽数字。
- Color：主体灰阶，单一蓝色强调。
- Radius / Shadow：仅使用命名档位和双层阴影。
- Restraint：移除主控背景、黄色高亮、Chip 网格和重复操作入口。
- Wayfinding：嵌入态由业务页提供退出路径，全屏态提供明确“退出全屏”。
